# Semantic HTML Landing Page

This project was created as part of **Mulearn Learning Fest 2.0 — Web Development Challenge 1**.

## About
A simple landing page built using HTML5 semantic elements, focusing on proper page structure and accessibility.

## Features
- Semantic HTML5 structure
- Proper heading hierarchy
- Accessible contact form
- Navigation with section links
- ARIA label for navigation

## Technology Used
- HTML5
